Vì sao có đoạn đầu dài? Lệnh bật sẵn TLS 1.2 (số 3072) trước khi tải — nếu không, PowerShell cũ báo lỗi “Could not create SSL/TLS secure channel”.
Trình cài tự: tải Node + agent → ghi cấu hình → đăng ký tự chạy khi đăng nhập → chạy ngay. Hỏi UAC 1 lần để bật loại trừ Windows Defender (cho phép chụp màn hình). Máy sẽ hiện trong bảng giám sát sau vài giây.
